CucinaSpave — GitHub Pages (Menu Editor + Firebase Sync)

1) Carica tutti i file nella root del repo GitHub.
2) Settings → Pages → Deploy from a branch (main / root).
3) Apri l’URL. In alto: Configura Realtime → incolla la config Firebase.
4) Usa Modifica menù per gestire categorie (Appetizer, Burgers, Dolci) e ingredienti.
